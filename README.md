# ProjectSCP-SCP3166-v73-hotfix
Hotfix for ProjectSCP-SCP3166 for v73

This mod is intended to fix the problem when Gorfield didn't change his behaviour. He was always passive due to the lack of updated to this mod. I created a dll that fixes this bug.

Instruction:

1) Download .zip file
2) Drag the folder "SCP3166RpcInitHelper" to "...\Lethal Company\BepInEx\plugins"
3) You should have a file "...\Lethal Company\BepInEx\plugins\SCP3166RpcInitHelper\SCP3166RpcInitHelper.dll" at the end
5) Done! Start playing.

Optional: If your Lasagna costs 0 you should change its default price in the config to some other value. Config file of SCP3166 can be found here "..\Lethal Company\BepInEx\config\ProjectSCP.SCP3166.cfg"
